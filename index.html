Где взять CSV/PDF выписку из банка?
  • Т-Банк: Операции → Фильтр за 3–6 мес → иконка «Выписка» → CSV
  • Сбер: История → Заказать выписку → период 6 мес → PDF
  • Альфа-Банк: История → Выписка по счёту → CSV / Excel (можно Ctrl+V)
  • Revolut / Monzo / Chase: Statements → Export CSV (3–6 months)
